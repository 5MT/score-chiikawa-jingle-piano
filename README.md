# ちいかわ ジングル / Chiikawa Jingle

アニメ「ちいかわ」のジングルのピアノ譜です。楽譜はABC記法で書かれ、同梱のabcjsで描画しています。
`score-chiikawa-jingle-piano.html`をブラウザーで開いてください。印刷時は用紙をA4縦、倍率を100%（実際のサイズ）に設定し、ブラウザーのヘッダーとフッターをオフにしてください。
印刷用PDF: [score-chiikawa-jingle-piano.pdf](./score-chiikawa-jingle-piano.pdf)

This repository contains a piano score for the jingle from the anime *Chiikawa*. The score is written in ABC notation and rendered with the included abcjs library.
Open `score-chiikawa-jingle-piano.html` in a browser to view or print the score. For printing, use A4 portrait paper at 100% scale and disable the browser's headers and footers.
Print-ready PDF: [score-chiikawa-jingle-piano.pdf](./score-chiikawa-jingle-piano.pdf)
